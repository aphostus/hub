  {The website goes through; Router>Loader>Path1/Path2.
  Path1(Account Signin/Signup > Account Setup),
  Path2(Phostack(Deskspace) > Settings(INAP+UI+P[Menu]) | Phobos(INAP+UI)|

  {Define('>'): Forward Process Direction, Define('/'): OR gate but strict
  Define('|'): Or gate but unstrict Define('Path'+[NO]): Types of paths or directory
  Define(PathAttributes = Example;About(INAP) then 'INAP' = An Attribute):
  For INAP; Means In the app display
  For UI; Has a separate render
  For P; Means the parent displayer
  For HOST: Means an available parent
  For DRCT: External file directory
  Define('/*\'): Means "Others" Not a gate but still a condition(IF)
  Notes: If has more than one then let it be, it means what it means}
)

(Deskspace Workflow:
  {The deskspace concepts is kept from the original aphostac website
  because it is seen as the main product of Aphostus via Phostack
  It should look about nearly the same from the old design for mobile versions
  but a new concept to how 'blocks' are}
  --- --- ---
  {Define("Blocks"): Has 3 layers; Displayer, Operator, Sourcer.
  Define('Displayer{(DPR)}'): The visible layer of a component,
  Define('Operator{(ORR)}'): The operator that connects the displayer and sourcer,
  Define('Sourcer{(SRR)}'): The hidden layer with infos, customs, links, API's etc
  Example: Blocks: (Notes.cpnt{[DPR: Rich Texts][ORR: Get SRC1 then AI Summary][SRR: SRC1=Fetch~https://google.my.docs]})
    CPNT(File Extension Format) Means Component Package for Phostack
    The package is in '()' while layers are in '{}' and types of layers '[]'
  Summary: Notes.cpnt displays a rich text AI summary from the source "SRC1"
  Components are stored in .cpnt if in the library for sharing and for downloading in the Library,
  in .blck (Block) format if in the deskspace grid, but reworked. a cpnt + blck are stored in a database document
  in one casing which is browsable in MongoDB(Database)}
)
