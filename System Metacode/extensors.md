# extensors.md - (Filextors)
> Custom file formats innovated by aphostus to support phostack development

Filextors are innovative extensions of aphostus, an actual aphostus project
that is well established. It is purposed to be an alternative
to modern file extensions, now Phostack is taking part of it today.

## {.blck}
Stands for **Block(s)**, this is used in the grid like a cpnt
but a useable version which is dynamic, input fillable and client based,
where the actual fun is.

--- --- ---

## {.cpnt}
Stands for **Component(s)**, this is used in the library thats like a blck
but protable not useable nor dynamic, like the structure of blck to be
converted later, where community is built and actually contains the js, html, css
parts.

--- --- ---
## {.uwrp}
Stands for **Universal Wrapping System**, an original aphostus filexter(ic) member
and under heavy development, current uwrap version is local only
made special for Phostack usage.

--- --- ---

## <(@)>
Stands for the **Converter**, Used to convert a cpnt and blck to their opposite
version when needed. example: (@).ts (Typescript Format). A logic system used inside
the phostack website useable when needed. Also creates a .uwrp for MongoDB file upload
which is a collection of .blck + .cpnt together.
